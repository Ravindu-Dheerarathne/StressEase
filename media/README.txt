Put your real yoga media files here. The app looks for these names:

Images (pose photos):
  pose1.jpg
  pose2.jpg
  pose3.jpg
  pose4.jpg

Audio (spoken instructions, one per stress level):
  audio-low.mp3
  audio-moderate.mp3
  audio-high.mp3

If a file is missing, the app automatically shows a "dummy placeholder"
box instead, so the website still works without any media.

To change which files are used, edit YOGA_ROUTINES in ../data.js
